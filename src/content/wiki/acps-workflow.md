# ACPS Workflow (Autoresearch‑based Continuous Process Selection)

The ACPS workflow is an experimental methodology that uses an "Autoresearch" loop to iteratively improve the software development process itself.

## Core Components

- **[Methodology Details](./acps-workflow/memory/acps-methodology.md)**: Deep dive into the ACPS philosophy and structure.
- **[States & Lifecycle](./acps-workflow/memory/acps-states.md)**: Understanding the different states an agentic task can be in.
- **[BCP Rubric](./acps-workflow/memory/bcp-rubric.md)**: Business Case and Planning rubric for assessing requirements.

## The Experiment Loop

The workflow is optimized by running cycles where an LLM (the researcher) suggests improvements to the implementation script, which are then tested against quality and performance metrics.

For detailed instructions on running this experiment, see the **[REPRODUCE_EXPERIMENT.md](../REPRODUCE_EXPERIMENT.md)** guide.
