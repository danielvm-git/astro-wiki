# BMAD Method Summary

## Overview
BMAD Method (Build More Architect Dreams) is an AI-driven agile development module for the BMad Method Module Ecosystem. It provides a comprehensive Agile AI Driven Development framework with scale-adaptive intelligence that adjusts from bug fixes to enterprise systems.

## Core Principles
- **AI Intelligent Help**: Invoke `bmad-help` skill for guidance on what's next
- **Scale-Domain-Adaptive**: Automatically adjusts planning depth based on project complexity
- **Structured Workflows**: Grounded in agile best practices across analysis, planning, architecture, and implementation
- **Specialized Agents**: 12+ domain experts (PM, Architect, Developer, UX, and more)
- **Party Mode**: Bring multiple agent personas into one session to collaborate and discuss
- **Complete Lifecycle**: From brainstorming to deployment

## Key Features
- 100% free and open source, no paywalls or gated content
- Scale-adaptive intelligence
- Structured, agent-assisted software delivery
- Uses Conventional Commits for every commit
- Quality checks via `npm ci && npm run quality`
- Skill validation system

## Quick Start
**Prerequisites**: Node.js v20.12+, Python 3.10+, uv
```bash
npx bmad-method install
```
For newest prerelease: `npx bmad-method@next install`

Non-interactive installation available for CI/CD.

## Integration with Hermes Agent
- Provides structured agile workflows for agent-assisted development
- Offers specialized agent personas for different roles (PM, Architect, etc.)
- Supports complete lifecycle from brainstorming to deployment
- Scale-adaptive intelligence helps adjust planning depth automatically
- Party mode enables multi-agent collaboration
