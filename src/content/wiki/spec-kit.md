# Spec-Kit (GitHub Specification Kit)

A toolkit for writing clear, concise, and actionable software specifications. Ideal for standardizing requirements that need to be understood by both humans and AI agents.

- **[Specification Kit Documentation](./spec-kit-repo/README.md)**
- **Goal:** Focus on WHAT, not HOW. Use clear sections for context, requirements, and constraints.
